# Telecom Design Patterns Seed

## Three-sector macro site

Typical macro sites use three sectors separated by 120 degrees. The default azimuth set
is `0, 120, 240` when the user requests three sectors but omits explicit azimuths.

## Rooftop mast

Rooftop masts are shorter and should keep antenna install height inside the mast range.

## Small-cell pole

Small-cell poles use compact antennas and lower installation heights than macro towers.
